# Система управления личными финансами

Backend-приложение для управления личными финансами на Java.

## Функциональность

- **Авторизация пользователей**: Регистрация и вход по логину и паролю
- **Управление финансами**: Добавление доходов и расходов с категориями
- **Бюджетирование**: Установка бюджета на категории расходов
- **Статистика**: Подсчет и отображение доходов, расходов и состояния бюджета
- **Сохранение данных**: Автоматическое сохранение и загрузка данных при запуске/завершении

## Структура проекта

```
src/main/
├── model/          # Модели данных
│   ├── User.java
│   ├── Wallet.java
│   ├── Transaction.java
│   └── Budget.java
├── service/        # Бизнес-логика
│   ├── AuthService.java
│   ├── WalletService.java
│   ├── BudgetService.java
│   ├── StatisticsService.java
│   └── FileService.java
├── ui/             # Пользовательский интерфейс
│   └── CommandLineInterface.java
└── Main.java       # Точка входа
```

## Компиляция и запуск

```bash
# Компиляция
javac -d out -sourcepath src/main src/main/*.java src/main/model/*.java src/main/service/*.java src/main/ui/*.java

# Запуск
java -cp out Main
```

## Использование

1. При первом запуске зарегистрируйте нового пользователя
2. Войдите в систему используя логин и пароль
3. Добавляйте доходы и расходы, указывая категории
4. Устанавливайте бюджеты на категории расходов
5. Просматривайте статистику и сохраняйте её в файл

## Примеры команд

- Добавление дохода: категория "Зарплата", сумма 20000
- Добавление расхода: категория "Еда", сумма 500
- Установка бюджета: категория "Еда", лимит 4000
- Просмотр статистики: автоматический расчет всех показателей

## Формат данных

Данные сохраняются в файлы `логин.txt` для каждого пользователя в следующем формате:
- `USER:логин:пароль` - информация о пользователе
- `TRANSACTION:TYPE:категория:сумма:дата` - транзакция
- `BUDGET:категория:лимит` - бюджет на категорию
